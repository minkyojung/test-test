# 에어비앤비 클론 페이지 작업 계획

현재 저장소에는 테스트/빌드 스크립트나 커밋 메시지 규칙이 없다. 각 작업은 정적 파일을 추가하거나 수정하며, 완료 확인은 브라우저에서 `index.html`을 열어 확인하는 방식으로 둔다.

- [x] 1. Add the static page shell
  - `index.html`을 추가해 앱 루트, 상단 히어로/브랜드 영역, 검색 영역, 숙소 목록 영역, 상세 영역의 기본 마크업을 만든다.
  - `styles.css`를 연결하고 `src/main.js`를 로드한다.
  - _Requirements: 1.1_
  - _Done when: 브라우저에서 `index.html`을 열었을 때 상단 영역, 검색 영역, 숙소 목록이 들어갈 영역, 상세 영역이 오류 없이 표시된다._

- [x] 2. Add sample stay data and listing rendering
  - `src/main.js`를 추가해 샘플 숙소 데이터를 정의하고, 초기 숙소 카드 목록을 렌더링한다.
  - 카드에는 이미지, 이름 또는 위치, 가격, 평점이 표시되게 한다.
  - 숙소 데이터가 비어 있는 경우 빈 상태 메시지를 렌더링하는 분기를 포함한다.
  - _Requirements: 1.1, 1.2, 1.3_
  - _Done when: 브라우저에서 `index.html`을 열었을 때 여러 숙소 카드가 보이고 각 카드에 이미지, 이름/위치, 가격, 평점이 표시된다._

- [x] 3. Style the responsive Airbnb-inspired layout
  - `styles.css`에 모바일 우선 레이아웃, 상단 히어로 스타일, 검색바 스타일, 반응형 숙소 카드 그리드를 추가한다.
  - 작은 화면에서는 검색 필드와 카드가 한 열로 쌓이고, 넓은 화면에서는 카드가 여러 열로 배치되게 한다.
  - 실제 에어비앤비 브랜드 자산을 복제하지 않고 카드 중심의 독자적 시각 스타일을 적용한다.
  - _Requirements: 1.1, 1.4_
  - _Done when: 브라우저 폭을 모바일 크기와 데스크톱 크기로 바꿔도 헤더, 검색 영역, 숙소 카드의 주요 정보가 잘리지 않고 보인다._

- [x] 4. Add search and trip condition filtering
  - `index.html`의 검색어 입력, 날짜 입력, 인원 선택 요소와 `src/main.js`의 필터 상태를 연결한다.
  - 검색어는 숙소 이름, 위치, 설명을 기준으로 목록을 좁히고, 날짜와 인원 조건은 샘플 데이터의 이용 가능 날짜와 수용 인원을 기준으로 목록을 좁힌다.
  - 조건 변경 시 목록을 다시 렌더링하고, 결과가 없으면 빈 결과 메시지를 표시한다.
  - _Requirements: 2.1, 2.2, 2.3, 2.4_
  - _Done when: 브라우저에서 검색어, 날짜, 인원을 바꾸면 숙소 목록이 즉시 바뀌고 조건에 맞는 숙소가 없을 때 결과 없음 메시지가 표시된다._

- [x] 5. Add stay detail and missing-detail states
  - `src/main.js`에 카드 선택 상태를 추가하고, 카드를 선택하면 상세 영역에 큰 이미지, 기본 정보, 설명, 편의 정보, 가격, 평점을 표시한다.
  - 상세 영역에 목록으로 돌아가기 버튼을 추가해 선택 상태를 해제하고 목록을 다시 보여준다.
  - 존재하지 않는 숙소 id가 선택된 상태에서도 오류를 던지지 않고 찾을 수 없음 메시지와 목록으로 돌아가기 동작을 표시한다.
  - _Requirements: 3.1, 3.2, 3.3, 3.4_
  - _Done when: 브라우저에서 숙소 카드를 선택하면 상세 정보가 보이고, 목록으로 돌아가기가 동작하며, 존재하지 않는 상세 id 상태에서도 찾을 수 없음 메시지가 표시된다._
