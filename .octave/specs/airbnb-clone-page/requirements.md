# 에어비앤비 클론 페이지

에어비앤비의 핵심적인 숙소 탐색 경험을 참고한 클론 페이지를 만들어, 방문자가 숙소 목록을 보고 조건을 바꿔가며 원하는 숙소를 살펴볼 수 있게 한다.

현재 저장소에는 `README.md`만 있고, 애플리케이션 코드나 화면, 테스트 구조는 아직 없다. 따라서 이 작업은 기존 기능을 수정하는 것이 아니라 새 페이지/앱의 첫 사용자 화면을 만드는 작업으로 시작한다.

## Requirements

### Requirement 1
방문자는 에어비앤비를 연상시키는 숙소 탐색 페이지를 볼 수 있다.

#### Acceptance Criteria
1. 페이지를 열면 서비스 성격을 알 수 있는 상단 영역, 숙소 탐색 영역, 숙소 카드 목록이 화면에 표시된다.
2. 각 숙소 카드는 최소한 숙소 이미지, 이름 또는 위치, 가격, 평점 정보를 표시한다.
3. 숙소 카드가 0개일 때는 빈 화면 대신 숙소가 없다는 상태 메시지가 표시된다.
4. 화면은 데스크톱과 모바일 폭에서 주요 정보가 잘리지 않고 확인된다.

### Requirement 2
방문자는 표시된 숙소를 조건으로 탐색할 수 있다.

#### Acceptance Criteria
1. 방문자는 목적지 또는 검색어를 입력해 숙소 목록을 좁힐 수 있다.
2. 방문자는 날짜 또는 인원 같은 여행 조건을 입력하거나 선택할 수 있다.
3. 조건에 맞는 숙소가 없으면 결과가 없다는 메시지가 표시된다.
4. 검색 조건을 변경하면 화면의 숙소 목록이 변경된 조건을 반영한다.

### Requirement 3
방문자는 숙소의 상세 정보를 확인할 수 있다.

#### Acceptance Criteria
1. 숙소 카드를 선택하면 해당 숙소의 더 자세한 정보가 표시된다.
2. 상세 정보에는 카드에 보이던 기본 정보와 함께 설명 또는 편의 정보가 표시된다.
3. 상세 정보에서 다시 목록으로 돌아갈 수 있다.
4. 존재하지 않는 숙소 상세를 열려고 하면 오류로 멈추지 않고 찾을 수 없다는 메시지가 표시된다.

## Out of Scope
- 실제 에어비앤비 계정 로그인, 회원가입, 결제, 예약 확정 기능.
- 실제 에어비앤비 데이터 또는 API 연동.
- 호스트 등록, 숙소 관리, 관리자 기능.
- 실제 브랜드 자산을 그대로 복제하는 것.

## Decisions for You
- 구현 범위 — 단일 페이지 데모, 여러 페이지 앱, 또는 실제 백엔드가 있는 앱 중 선택이 필요하다. 추천은 단일 페이지 데모이며, 현재 저장소가 비어 있어 가장 작게 완성 여부를 확인할 수 있기 때문이다. Until they say otherwise, the requirements above assume 단일 페이지 데모.
- 시각적 유사도 수준 — 에어비앤비와 매우 비슷한 화면, 또는 에어비앤비에서 영감을 받은 독자적 화면 중 선택이 필요하다. 추천은 에어비앤비에서 영감을 받은 독자적 화면이며, 실제 브랜드 자산을 그대로 복제하지 않으면서 클론코딩 학습 목적을 달성할 수 있기 때문이다. Until they say otherwise, the requirements above assume 에어비앤비에서 영감을 받은 독자적 화면.
